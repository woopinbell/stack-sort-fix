# stack-sort

두 개의 스택과 제한된 연산만으로 정수 목록을 오름차순 정렬하는 C 프로젝트입니다.
`push_swap`은 정렬 명령을 생성하고, `checker`는 그 명령을 적용해 결과를 검증합니다.

## 주요 기능

- 여러 명령줄 인자와 한 인자 안에서 공백으로 나뉜 값을 같은 방식으로 처리합니다.
- 숫자 형식, 32비트 정수 범위, 중복 여부를 검사합니다.
- 5개 이하의 입력에는 작은 스택 정렬을 사용합니다.
- 더 큰 입력에는 좌표 압축과 LSD 기수 정렬을 사용합니다.
- 이미 정렬된 입력에는 아무 명령도 출력하지 않습니다.
- 두 프로그램이 동일한 스택 연산 구현을 공유합니다.

## 빌드

```sh
make
```

빌드가 끝나면 `push_swap`과 `checker`가 생성됩니다.

C 컴파일러와 `make`가 필요하며, 테스트를 실행할 때는 Python 3을 사용합니다.

빌드 산출물을 정리하거나 처음부터 다시 빌드할 때는 다음 명령을 사용합니다.

```sh
make clean
make fclean
make re
```

## 사용법

정수를 개별 인자나 하나의 문자열로 전달할 수 있습니다.

```sh
./push_swap 3 2 1
./push_swap "3 2 1"
./push_swap 3 2 1 | ./checker 3 2 1
```

`push_swap`은 한 줄에 하나씩 연산을 출력합니다. `checker`는 연산을 모두 적용한
결과에 따라 `OK` 또는 `KO`를 표준 출력에 기록하고 종료 코드 0으로 끝납니다.
입력값이나 연산 이름이 잘못되면 `Error`를 표준 오류로 출력하고 0이 아닌 종료
코드로 끝납니다.

## 정렬 방식

입력값은 크기 순서대로 `0`부터 `n - 1`까지의 순위로 변환합니다. 5개 이하의 입력은
가장 작은 값을 보조 스택으로 옮긴 뒤 2개 또는 3개 전용 정렬을 적용합니다. 더 큰
입력은 순위의 비트를 차례로 확인하는 LSD 기수 정렬을 사용합니다.

지원하는 연산은 `sa`, `sb`, `ss`, `pa`, `pb`, `ra`, `rb`, `rr`, `rra`, `rrb`,
`rrr`입니다.

## 테스트

```sh
make test
```

테스트 러너는 입력 검증, 모든 스택 연산, 작은 입력의 전체 순열과 다양한 크기의
정렬 결과를 확인합니다. 고정된 난수 입력으로 반복 검증하며, 입력 크기별 명령 수가
정해 둔 상한을 넘지 않는지도 함께 검사합니다.

## 구조

```text
include/push_swap.h     공용 타입과 함수 선언을 관리합니다.
src/parser.c            입력 검증과 좌표 압축을 담당합니다.
src/stack.c             스택의 생성, 해제, 상태 확인을 담당합니다.
src/operations.c        교환, 이동, 회전 연산을 구현합니다.
src/sort.c              작은 입력 정렬과 기수 정렬을 구현합니다.
src/push_swap.c         정렬 명령 생성 프로그램을 실행합니다.
src/checker.c           명령 적용과 정렬 결과 판정을 담당합니다.
src/checker_reader.c    표준 입력에서 명령을 한 줄씩 읽습니다.
src/utils.c             문자열 비교와 출력 함수를 제공합니다.
tests/run_tests.py      두 실행 파일의 동작을 함께 검증합니다.
```

## 범위

입력은 32비트 부호 있는 정수로 제한합니다. 정렬 전략은 예측 가능하고 검증하기 쉬운
명령 흐름에 초점을 맞추며, 모든 입력에서 가능한 최소 명령 수를 보장하지는 않습니다.
