# stack-sort

두 개의 스택과 제한된 연산만으로 정수 목록을 오름차순 정렬하는 C 프로젝트입니다.
정렬에 필요한 명령을 계산하는 `push_swap`과, 명령을 적용해 결과를 확인하는
`checker`를 구현합니다.

## 구현 방향

구현은 다음 순서로 진행합니다.

1. 두 실행 파일의 빌드 구조와 공용 인터페이스를 구성합니다.
2. 스택 저장 구조와 교환·이동·회전 연산을 구현합니다.
3. 입력을 검증하고 값의 상대적인 순위를 계산합니다.
4. 입력 크기에 맞는 정렬 전략으로 명령을 생성합니다.
5. 생성한 명령을 독립적으로 검증하고 회귀 테스트를 추가합니다.
