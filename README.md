# stack-sort

두 개의 스택과 제한된 연산만으로 정수 목록을 오름차순 정렬하는 C 프로젝트입니다.
`push_swap`은 입력을 검증하고 정렬에 필요한 명령을 출력합니다.

## 정렬 방식

입력값은 크기 순서대로 `0`부터 `n - 1`까지의 순위로 변환합니다. 5개 이하의 입력은
작은 스택 정렬로 처리하고, 더 큰 입력은 순위의 비트를 차례로 확인하는 LSD 기수
정렬을 사용합니다. 이미 정렬된 입력에는 아무 명령도 출력하지 않습니다.

## 빌드

현재 정렬 프로그램은 다음 명령으로 빌드할 수 있습니다.

```sh
make push_swap
```

## 사용법

정수를 개별 인자나 하나의 문자열로 전달할 수 있습니다.

```sh
./push_swap 3 2 1
./push_swap "3 2 1"
```

잘못된 숫자 형식, 32비트 정수 범위를 벗어난 값, 중복된 값에는 `Error`를
표준 오류로 출력합니다.

## 지원 연산

`sa`, `sb`, `ss`, `pa`, `pb`, `ra`, `rb`, `rr`, `rra`, `rrb`, `rrr`을
지원합니다. 정렬 프로그램과 검증 프로그램은 같은 연산 구현을 공유합니다.
