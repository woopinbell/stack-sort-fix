# stack-sort

두 개의 스택과 제한된 연산만으로 정수 목록을 오름차순 정렬하는 C 프로젝트입니다.
정렬에 필요한 명령을 계산하는 `push_swap`과, 명령을 적용해 결과를 확인하는
`checker`를 함께 구성합니다.

## 프로그램 구성

- `push_swap`은 입력된 정수를 정렬하는 데 필요한 스택 연산을 출력합니다.
- `checker`는 표준 입력으로 받은 연산을 적용한 뒤 정렬 여부를 알려 줍니다.

두 프로그램은 파서와 스택 연산을 공유합니다. 공용 타입과 함수 선언은
`include/push_swap.h`에서 관리하며, 각 실행 파일의 진입점만 분리합니다.

## 개발 순서

스택 저장 구조와 기본 연산을 먼저 구현한 뒤 입력 처리, 정렬, 검증 순서로 기능을
연결합니다. 마지막에는 Python 테스트 러너로 두 프로그램을 함께 검증합니다.
