# stack-sort

두 개의 스택과 제한된 연산만으로 정수 목록을 오름차순 정렬하는 C 프로젝트입니다.
`push_swap`은 정렬 명령을 생성하고, `checker`는 그 명령을 적용해 결과를 검증합니다.

## 핵심 동작

- 여러 명령줄 인자와 한 인자 안에서 공백으로 나뉜 값을 같은 방식으로 처리합니다.
- 숫자 형식, 32비트 정수 범위, 중복 여부를 검사합니다.
- 5개 이하의 입력에는 작은 스택 정렬을 사용합니다.
- 더 큰 입력에는 좌표 압축과 LSD 기수 정렬을 사용합니다.
- 이미 정렬된 입력에는 아무 명령도 출력하지 않습니다.

## 빌드와 사용법

```sh
make
./push_swap 3 2 1
./push_swap "3 2 1"
./push_swap 3 2 1 | ./checker 3 2 1
```

`checker`는 연산을 모두 적용한 결과에 따라 `OK` 또는 `KO`를 출력합니다. 입력값이나
연산 이름이 잘못되면 `Error`를 표준 오류로 출력합니다.

## 테스트

```sh
make test
```

테스트 러너는 입력 검증, 모든 스택 연산, 작은 입력의 전체 순열과 다양한 크기의
정렬 결과를 확인합니다. 고정된 난수 입력으로 반복 검증하며, 입력 크기별 명령 수가
정해 둔 상한을 넘지 않는지도 함께 검사합니다.
