# stack-sort

두 개의 스택과 제한된 연산만으로 정수 목록을 오름차순 정렬하는 C 프로젝트입니다.
정렬에 필요한 명령을 계산하는 `push_swap`과, 명령을 적용해 결과를 확인하는
`checker`를 함께 구성합니다.

## 스택 모델

각 스택은 배열의 0번 위치를 맨 위로 사용합니다. 원래 정수 값과 정렬에 사용할
상대 순위를 같은 위치에 보관하므로, 스택이 움직일 때 두 배열도 함께 이동합니다.

지원하는 연산은 다음과 같습니다.

- `sa`, `sb`, `ss`는 스택 맨 위의 두 값을 교환합니다.
- `pa`, `pb`는 한 스택의 맨 위 값을 다른 스택으로 옮깁니다.
- `ra`, `rb`, `rr`는 스택을 위쪽으로 회전합니다.
- `rra`, `rrb`, `rrr`는 스택을 아래쪽으로 회전합니다.

동일한 연산 함수를 두 프로그램이 공유하되, `push_swap`에서 실행할 때만 연산 이름을
출력하도록 구성합니다.

## 프로그램 구성

- `push_swap`은 입력된 정수를 정렬하는 데 필요한 스택 연산을 출력합니다.
- `checker`는 표준 입력으로 받은 연산을 적용한 뒤 정렬 여부를 알려 줍니다.

공용 타입과 함수 선언은 `include/push_swap.h`에서 관리하며, 각 실행 파일의
진입점만 분리합니다.
