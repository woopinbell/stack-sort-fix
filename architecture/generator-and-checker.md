# 생성부터 검증까지

## 입력 파서는 두 프로그램이 공유한다

`push_swap`과 `checker`는 모두 `parse_input`으로 A 스택을 만든다. argv 하나에 여러 숫자가 들어오는 경우와 여러 argv에 나뉜 경우를 같은 공백 규칙으로 토큰화한다.

파서는 먼저 전체 토큰 수가 `int`와 할당 크기에 들어오는지 확인하고 스택 배열을 만든다. 각 숫자는 부호 뒤에 적어도 한 자리 숫자가 있어야 한다. `src/parser.c`는 숫자를 `long long`에 누적하고 각 자리를 반영한 직후 양수 `INT_MAX`, 음수 `INT_MAX + 1` 한계를 검사한다. 반복이 다음 자리까지 이어졌다면 직전 값은 이 한계 이하이다. 32비트 `int`인 현재 검증 환경에서 `long long`으로 계산하는 다음 식의 최댓값도 `((long long)INT_MAX + 1) * 10 + 9`, 즉 `21474836489`이므로 `LLONG_MAX`보다 작다. 따라서 매우 긴 숫자열도 `long long`이 넘치기 전에 처음 `int` 범위를 벗어난 자리에서 거절된다.

복사한 값 배열을 정렬해 중복을 찾고 이진 검색으로 순위를 배정한다. 파싱이나 순위 배열 할당이 실패하면 A를 빈 상태로 되돌린다.

## 값과 순위를 함께 움직인다

`include/push_swap.h`는 두 실행 파일이 공유하는 `t_stack`, 연산, parser와
런타임 함수의 내부 계약을 모은다.

```c
typedef struct s_stack
{
    int *values;
    int *ranks;
    int size;
    int capacity;
} t_stack;
```

정렬 알고리즘은 `ranks`만 비교하지만 최종 결과는 원래 `values`다. 모든 swap, push, rotate는 두 배열의 같은 인덱스를 함께 움직여야 한다. 둘이 어긋나면 명령열은 순위 기준으로는 맞아 보여도 실제 값 순서가 틀린다.

`tests/operation_invariants.c`는 11개 연산마다 값과 순위의 쌍, 두 스택 전체의 원소 집합을 확인한다.

## 생성기와 검사기는 연산 구현을 공유한다

연산 함수의 `emit` 인자가 참이면 상태 변경 뒤 명령을 stdout에 쓴다. `push_swap`은 `emit=1`, checker는 입력 명령을 적용할 때 `emit=0`을 사용한다. 상태 전이 코드를 공유하면 생성기와 검사기 사이의 연산 의미가 달라지는 위험을 줄인다.

다만 같은 구현만으로 서로를 검증하면 공통 버그를 놓칠 수 있다. Python 테스트는 별도 리스트 모델로 명령을 재생해 정렬과 원소 보존을 확인하고, 그 명령을 실제 checker에도 전달한다.

## checker 입력 경계

명령 버퍼는 `PS_COMMAND_MAX + 1`로 고정되어 있다. 한 바이트씩 읽으면서 `EINTR`는 재시도하고, 개행 또는 EOF에서 한 명령을 끝낸다. 최대 길이를 넘거나 NUL이 나오면 즉시 오류다.

읽기 실패와 명령 오류에서는 일부 상태를 `OK`나 `KO`로 판정하지 않는다. 프로토콜 오류와 정렬 실패는 다른 종류이므로 전자는 `Error`, 후자는 `KO`다.

## 두 실행 파일에서 끝나는 흐름

`src/push_swap.c`는 입력으로 A를 만들고 같은 용량의 빈 B를 준비한 뒤
`src/sort.c`에 두 스택을 넘긴다. `src/checker.c`도 준비 과정은 같지만
`src/checker_reader.c`에서 명령을 읽어 `apply_checker_command`로 적용한다.
마지막에는 A의 정렬과 B의 빈 상태를 함께 확인한다.

두 경로 모두 `src/stack.c`의 생성·정리와 `src/operations.c`의 상태 전이를
공유한다. `src/runtime.c`는 할당과 읽기·쓰기, SIGPIPE 정책을 한곳에 모으고,
테스트 빌드에서 같은 경계에 실패와 작업량 관찰을 끼워 넣는다.
`src/utils.c`는 문자열 비교와 오류 출력처럼 두 실행 파일에 필요한 작은 기능만
맡는다. 이 연결 파일들은 독립 알고리즘은 아니지만 입력부터 종료까지 누가
스택과 외부 효과를 정리하는지 보여 주는 경계다.
